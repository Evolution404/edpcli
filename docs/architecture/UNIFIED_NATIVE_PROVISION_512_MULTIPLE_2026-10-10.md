# 全模式制盘统一几何阶段记录（2026-10-10）

分支：feat/native-4kn-wal-staging-20261010。阶段：P0 几何通用化、P1 原生离线写集部分实现；实体写入门禁未解除。

## 已落实

- 原生几何接受 512*n（n>=1），与协议内部固定 512B 字段分开；设备身份和容量复核规则不因此开放任何物理写权。
- 通用预填统一 Native LBA、MiB/GiB 字节换算以及原生块向上取整。来源模式、目标模式独立建模；5×5×9=225 个来源/目标/几何规划矩阵断言。
- 原生 EDP 离线镜像核心改为 plan_native_edp_image(..., logical_sector_bytes)，老 4Kn 命名入口仅为兼容转发，遵守同一套协议、LCE、格式化、加密和写集逻辑。
- 固定 3072B LCE 内容按计算所得原生块大小连续加密，再拆分为完整原生 LBA 块（修复旧版在小块几何下产生一个超长 I/O 块的缺陷）。
- 离线协议/LCE 回解析：4 种 EDP 模式 × 8 个原生几何；加密：3 种数据算法 × 8 个几何往返，新增负向不对齐断言。
- 512B 原有协议、文件系统、目标身份证明和物理写盘授权仍有独立金标及回归保护。

## 尚未完成：不得宣称完成全模式正式制盘

- 25 个模式组合当前完成几何规划，不代表每个组合的文件系统、FileKey、LCE 来源迁移、实盘回读已验证。Plain 目标仍采用独立旧规划入口。
- 512B 正式 prepare/commit 与非 512B 原生预检、虚拟计划仍未接入一个完整不可变应用层写集；旧 Mode0→Mode1 来源认证限制仍存在，不能通过简单删除放行。
- TUI 快速容量输入的 512B 固定单位、实体设备能力判定和完整新模式编辑仍待清理；现阶段 UI 原生布局预览仅只读。
- FAT16/FAT32/exFAT 格式化必须由文件系统规范的实际支持范围决定；几何上合法的 1536B、2560B 等不意味着可创建可挂载文件系统。
- U391 本轮没有执行实盘写入、挂载/解锁/读写/重插验证。未经新鲜备份、身份锁定、WAL 和用户授权，不开放设备写入。

门禁：cargo fmt、Clippy、fast/full、redundancy audit，并在实体验收和并行架构收口后方可解除 PR Draft。

## 2026-10-10 P1b：原生虚拟 I/O、WAL 与文件系统能力独立认证

- 修复第二处真实阻断：`validate_virtual_image_plan`、`write_native_virtual_plan`、`NativeTransaction`、`NativeJournal` 与 WAL 恢复解析器均已按共同的 `512*n` 原生完整块长度校验，而非固定 512/4096 白名单。
- 使用**真实普通稀疏文件 I/O** 对 512、1024、1536、2048、2560、3072、4096、8192B 原生写集完成写入、独立重新打开回读；实体 raw USB 未触碰。
- WAL 在相同八种规格下执行持久化快照、模拟中断、受身份绑定的恢复、原始块逐字节回读，并保持 LBA0 最后恢复；含既有故障注入与负例测试。
- Plain 的 MiB/GiB 改为绝对字节容量向上取整至原生块，不再要求字节数天然可整除原生扇区。
- 将 FAT12/FAT16/FAT32/exFAT 原生格式化的扇区规格由历史白名单统一成**文件系统层标准能力**：512～4096B 的 2 的幂大小（512/1024/2048/4096B）；1536/2560/3072/8192B 虽可进行原生协议/I/O/WAL，但应拒绝生成假合法 FAT/exFAT。
- 对 FAT16/FAT32/exFAT 的四种标准规格运行元数据格式化与原生引导扇区再次识别；Plain FAT16 使用 512/1024/2048/4096B 稀疏文件验证。该能力不意味着不同 Windows/Linux/macOS 版本都能挂载所有组合。
- 所有改动只影响离线文件和原生块模型，不解除 CLI/TUI 实体制盘身份/写入授权门禁。全来源→全目标的 FileKey 与实体转换事务仍未完成。

## 2026-10-10 P1c：TUI 原生容量与全来源→目标只读几何审核

- 消除 Plain 目标表单使用 `row.size / 512` 推导原生扇区数量的问题：所有已观测介质通过 `layout_geometry().native_sector_count` 建立一致 LBA 空间，不对 4Kn 设备虚增 8 倍容量。
- `ProvisionForm` 和 `PlainProvisionForm` 绑定设备实际逻辑扇区大小。MiB/GiB 编辑、精确 LBA、单位循环、填满操作沿用同一几何；512B 旧舍入行为保留，其他 512*n 容量输入按完整原生块向上取整。
- TUI 的非 512B 来源→目标分两级：已验证 4Kn Mode0→Mode1 且持有唯一来源备份时保留原来源绑定认证专用预检；其他已观测来源/目标组合可进入**独立的只读目标几何审核**，不再错误地提示“来源必须是Mode0”。
- 普通盘来源没有 LCE 是正常状态；只读新 EDP 草稿允许将盘末完整原生块标为**拟预留位置**，绝不能当作已发现的真实 LCE 或通过物理门禁。
- 通用几何审核不产出 `PreparedProvision`，不认证 FileKey/密码、文件系统完整性或来源内容，也不允许 Enter/导出进入执行。模式切换后的原计划仅作几何展示，不是转换可行性的正式证明。
- UI 回归包含 4Kn Mode0→Plain、Mode1→Mode1、Plain→Mode1、设备原生 LBA 数量，以及标准/非标准 512*n 容量单位解析与精确模式往返。
- **仍未完成**：通用不可变已认证 `NativeWriteSet`、25 组合的实际迁移/重封装/格式化、通用 WAL 设备租约联结、独立实盘解锁和挂载 HIL。旧 512B 正式写盘流程不受影响。
